## Traveling Salesman Problem (TSP) в SQL

В рамках данного проекта была реализована классическая задача коммивояжёра с использованием SQL и рекурсивных запросов.

### Что сделано в проекте
- Смоделирован взвешенный граф перемещений между городами в реляционной базе данных
- Реализованы рекурсивные SQL-запросы для перебора возможных маршрутов
- Найдены оптимальные маршруты с минимальной суммарной стоимостью
- Дополнительно получены маршруты с максимальной стоимостью для сравнения
- Реализована сортировка и представление результатов в удобном аналитическом виде

### Используемый подход
Для решения задачи использовались рекурсивные запросы (CTE), позволяющие:
- обходить граф,
- формировать маршруты,
- вычислять суммарную стоимость тура,
- находить оптимальные и наихудшие решения.

### Результат
Проект демонстрирует умение:
- решать задачи оптимизации средствами SQL,
- работать с графовыми структурами в реляционных БД,
- применять рекурсивные запросы для аналитических задач.

### Технологии
- SQL (PostgreSQL)
