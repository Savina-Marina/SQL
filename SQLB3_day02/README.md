# SQL_day02 — Deep diving into JOINs in SQL

## О проекте
Этот репозиторий — учебный проект по SQL, в котором я отработала практические навыки работы с реляционными базами данных на примере модели «пиццерии». Основной фокус — корректное использование соединений таблиц (JOIN), работа с пропусками (NULL), построение запросов через CTE и генерацию диапазонов дат.

## Что я сделала и чему научилась
В ходе выполнения заданий я:
освоила логику реляционной алгебры и понимание того, как SQL-запросы интерпретируются как операции над отношениями; отработала основные типы JOIN и типичные сценарии их применения, включая поиск отсутствующих данных, построение полных выборок и корректную обработку NULL; переписала запросы с использованием CTE для повышения читаемости и структурирования логики; использовала генерацию рядов дат (generate_series) для поиска «пропусков» в данных; применяла фильтрацию и сортировку результатов с заданными требованиями к форматированию вывода.

## Ключевые темы проекта
JOINs: LEFT / RIGHT / FULL, работа с несколькими таблицами и связями через внешние ключи.  
CTE: вынесение генератора дат и частей логики в отдельные блоки.  
NULL-handling: замена NULL на заданные значения (например, '-') и корректное отображение неполных данных.  
Аналитические выборки: поиск отсутствующих посещений, предпочтений пользователей, дешёвых предложений и т.д.

## Модель данных
Проект построен вокруг простой модели PostgreSQL:
pizzeria (пиццерии), person (клиенты), menu (позиции меню), person_visits (посещения), person_order (заказы).  
Эта схема позволяет решать задачи на соединение сущностей и построение выборок, похожих на реальные аналитические запросы.

## Структура решений
Решения находятся в директории `src/` и разбиты по заданиям:
`src/ex00 ... src/ex10` — в каждой папке один SQL-файл формата `day02_exXX.sql`.

## Примеры выполненных задач
ex00: поиск пиццерий, которые никто не посещал (JOIN для выявления отсутствующих связей).  
ex01/ex03: поиск пропущенных дат посещений и переписывание запроса через CTE + генерацию дат.  
ex02: построение полного списка посещений и не-посещений с FULL JOIN и обработкой NULL.  
ex04–ex10: аналитические запросы к меню, заказам и посещениям с условиями по людям/городам/ценам.

## Стек
SQL (ANSI SQL), PostgreSQL, CTE, generate_series, JOINs.
