## SQL: работа с множествами и JOIN

В рамках данного проекта я отработала ключевые навыки SQL, необходимые для аналитики данных и работы с реляционными базами.

### Что сделано в проекте
- Работа с множествами данных с использованием `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`
- Поиск пересечений и различий между наборами данных
- Использование подзапросов и сортировки по нескольким столбцам
- Анализ дубликатов без применения `DISTINCT` и `GROUP BY`
- Применение различных типов соединений таблиц: `JOIN`, `NATURAL JOIN`
- Сравнение подходов `IN` и `EXISTS`
- Построение запросов для анализа пользовательских действий (визиты и заказы)

### Используемая модель данных
Проект основан на учебной модели базы данных (PostgreSQL), включающей:
- пользователей,
- пиццерии,
- меню,
- визиты,
- заказы.

Это позволило решать практические аналитические задачи, близкие к реальным бизнес-сценариям.

### Результат
Проект демонстрирует уверенное владение SQL для аналитики:
- умение извлекать и преобразовывать данные,
- работать с отношениями между таблицами,
- писать читаемые и логически выверенные запросы.

### Технологии
- SQL (PostgreSQL)
