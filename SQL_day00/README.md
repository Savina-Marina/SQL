# SQL Bootcamp — Day 00

**Реляционная модель данных и базовый SQL (PostgreSQL)**

## Описание проекта

Данный проект представляет собой набор практических SQL-задач, направленных на освоение основ работы с реляционными базами данных на примере PostgreSQL. В рамках проекта отрабатываются базовые конструкции SQL без использования сложных расширений и ORM.

Проект выполнен в формате учебного bootcamp и демонстрирует умение писать чистые, читаемые и логически корректные SQL-запросы.

## Используемые технологии

PostgreSQL
ANSI SQL

## Структура базы данных

В проекте используется модель базы данных для предметной области «пиццерии», включающая следующие сущности:
персоны, пиццерии, меню, посещения и заказы.
Данные между посещениями и заказами намеренно не связаны напрямую, что позволяет отрабатывать различные типы выборок и подзапросов.

## Что реализовано

В ходе проекта были написаны SQL-запросы, решающие следующие задачи:

• выборка данных с условиями фильтрации
• сортировка по одному и нескольким полям
• фильтрация по диапазонам дат и числовых значений
• использование подзапросов в SELECT и FROM
• работа с вычисляемыми столбцами
• применение условной логики (CASE)
• соблюдение ограничений (запрет JOIN, IN в отдельных заданиях)
• работа с чётными/нечётными идентификаторами

Каждое задание оформлено отдельным SQL-файлом и соответствует конкретному практическому сценарию.

## Цель проекта

Продемонстрировать уверенное владение базовым SQL, понимание реляционной модели данных и умение получать требуемую информацию из базы данных с помощью подзапросов и условий.

## Практическая ценность

Проект показывает готовность работать с реальными БД, писать запросы для аналитики, отчётности и серверной логики приложений без использования фреймворков.
