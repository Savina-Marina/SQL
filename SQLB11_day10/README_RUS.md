## Проект: Функции, триггеры и бизнес-логика в PostgreSQL

В этом проекте я изучила и реализовала перенос бизнес-логики на уровень СУБД с использованием функций и триггеров PostgreSQL.

### Что было сделано

* Разработка **триггеров и триггерных функций** для отслеживания изменений данных
* Реализация полноценного **аудита данных (INSERT / UPDATE / DELETE)**:

  * хранение старых и новых значений
  * фиксация типа события и времени изменения
* Объединение логики аудита в **универсальный триггер** для всей DML-активности
* Работа с **SQL-функциями и PL/pgSQL-функциями**
* Создание:

  * параметризованных функций
  * функций-обёрток над запросами
  * функций, возвращающих наборы данных (table-returning functions)
* Сравнение подходов **VIEW vs FUNCTION**
* Реализация прикладных алгоритмов на уровне БД (поиск минимума, числа Фибоначчи)

### Используемые технологии

* PostgreSQL
* SQL (DDL, DML)
* PL/pgSQL
* Триггеры и функции
* Работа с параметрами, массивами и возвращаемыми таблицами

### Практическая ценность

Проект показывает умение:

* выносить бизнес-логику в базу данных
* обеспечивать **целостность и контроль изменений данных**
* реализовывать аудит без зависимости от приложения
* писать переиспользуемые функции для аналитики и backend-задач
