## SQL-аналитика: агрегации и метрики

В данном проекте я выполняла анализ данных в PostgreSQL с использованием агрегатных функций для решения типовых бизнес-задач.

### Что сделано в проекте
- Выполнена агрегация данных с использованием `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
- Применена группировка данных (`GROUP BY`) и фильтрация агрегатов (`HAVING`)
- Построены аналитические отчёты по посещениям и заказам клиентов
- Рассчитаны метрики ресторанов: количество заказов, средняя, минимальная и максимальная цена
- Проанализировано поведение клиентов и популярность заведений
- Реализованы объединения данных из нескольких таблиц для построения сводной аналитики
- Выполнена сортировка и форматирование результатов для аналитических выводов

### Используемая модель данных
Проект основан на учебной реляционной модели (PostgreSQL), включающей данные о клиентах, пиццериях, меню, заказах и визитах.

### Результат
Проект демонстрирует навыки:
- преобразования сырых данных в аналитические отчёты,
- расчёта бизнес-метрик,
- анализа клиентского поведения,
- написания чистых и логичных SQL-запросов для аналитики.

### Технологии
