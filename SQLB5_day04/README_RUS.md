# SQL_day04 — Views, Materialized Views and Set Operations

## О проекте
Этот проект посвящён работе с виртуальными таблицами (VIEW) и материализованными представлениями (MATERIALIZED VIEW) в PostgreSQL.  
В рамках проекта я изучала, как абстрагировать данные с помощью представлений, работать с операциями над множествами, генерировать временные диапазоны, находить пропуски в данных и использовать материализацию для оптимизации запросов.

Проект логически продолжает предыдущие этапы (JOIN и DML) и моделирует реальные сценарии аналитики и оптимизации БД.

## Что я делала в этом проекте
В ходе выполнения заданий я:
создавала и использовала VIEW для фильтрации и объединения данных без изменения базовых таблиц; объединяла несколько представлений в единый интерфейс доступа к данным; генерировала временные диапазоны дат и использовала их для поиска пропущенных значений; применяла операции теории множеств (UNION, EXCEPT) для аналитических выборок; рассчитывала производные показатели (скидочные цены) внутри представлений; создавала MATERIALIZED VIEW для фиксации состояния данных; обновляла материализованные представления после изменения исходных данных; управляла жизненным циклом объектов БД (создание, обновление, удаление).

## Ключевые темы и навыки
- VIEW и MATERIALIZED VIEW  
- Различия между виртуализацией и материализацией данных  
- Set operations (UNION, EXCEPT)  
- generate_series и работа с временными диапазонами  
- Поиск пропусков в данных  
- Расчёт производных значений (скидки, цены)  
- REFRESH MATERIALIZED VIEW  
- Управление схемой базы данных  

## Примеры решённых задач
- Создание отдельных представлений для мужчин и женщин и объединение их в общий набор данных  
- Хранение сгенерированных дат в виде VIEW и поиск пропущенных дней посещений  
- Реализация симметрической разности наборов посещений через операции над множествами  
- Расчёт скидочной цены для каждого клиента на уровне представления  
- Создание и обновление материализованного представления для ускорения аналитического запроса  
- Очистка базы данных от временных представлений и materialized view после завершения работы
