## Оптимизация SQL-запросов и работа с индексами в PostgreSQL

В данном проекте я занималась анализом производительности SQL-запросов и их оптимизацией с использованием различных типов индексов PostgreSQL.

### Что сделано в проекте
- Созданы индексы для внешних ключей с целью ускорения JOIN-запросов
- Проанализирована работа индексов с помощью `EXPLAIN ANALYZE`
- Реализованы функциональные индексы и проверено их использование в запросах
- Созданы многоколоночные индексы для оптимизации фильтрации данных
- Реализованы уникальные и частично уникальные индексы для обеспечения целостности данных
- Подобран покрывающий индекс для ускорения сложного аналитического запроса с оконной функцией
- Проведено сравнение производительности запросов **до и после оптимизации**

### Результат
Проект демонстрирует умение:
- находить узкие места в SQL-запросах,
- читать и интерпретировать планы выполнения,
- осознанно применять индексы для повышения производительности,
- работать с реальными ограничениями и требованиями к данным.

### Технологии
- SQL (PostgreSQL)
- EXPLAIN / EXPLAIN ANALYZE
- B-Tree, функциональные, составные и частичные индексы
